Let users box-select nodes with a right-drag rectangle on the canvas. This
extends the selection controls from 18.1 (select all) with a spatial selection
gesture. React Flow's built-in selection box is left-button only, so this is a
separate hand-rolled marquee.

## Implementation

1. Right-drag marquee on the pane.
   - Listen for `mousedown` in the capture phase on the canvas wrapper (React
     Flow's pane consumes the event before it reaches React's delegated
     handlers).
   - Start a marquee only when `event.button === 2` **and** the target is
     inside `.react-flow__pane` — never on a node, an edge label, or an input,
     so those keep their native right-click behavior.
   - Track the drag with `window` `mousemove` / `mouseup` listeners in the
     capture phase; render a dashed rectangle following the cursor.
   - Hoist the move/up listeners so the effect cleanup detaches them too if the
     canvas unmounts mid-drag.

2. Selection on release.
   - Ignore a near-still right-click (< 4px in both axes) — leave selection
     untouched so a plain right-click is a no-op, not a "clear selection".
   - Hit-test every node's screen-space box (`flowToScreenPosition`, falling
     back to `SHAPE_DEFAULT_SIZE` when a node isn't measured yet) against the
     marquee rectangle.
   - Push one `replace` change per node through `onNodesChange` with
     `selected: <inside the box>` — same synced path `selectAll` uses, and
     `replace` (not `select`) so React Flow's single-selection reconciler
     doesn't clear all but one.

3. Context menu.
   - Suppress the browser context menu **only** when the target is inside
     `.react-flow__pane`. Nodes, edge labels, and text inputs keep their
     native menu (right-click paste / spellcheck while editing a label).

## Scope Limits

- right-button only — don't touch React Flow's left-button selection box
- don't add drag-to-move-selection, alignment, or grouping
- don't add a context menu of our own
- don't change node or edge rendering
- keep selection on the existing synced `onNodesChange` flow

## Check When Done

- Right-drag on empty canvas selects the enclosed nodes.
- Right-click (no drag) does not change selection.
- Right-click inside a node label / edge label still opens the browser menu.
- Marquee listeners don't leak if the canvas unmounts during a drag.
- `npm run build` passes.
