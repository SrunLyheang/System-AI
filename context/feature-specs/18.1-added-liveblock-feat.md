Make the canvas quicker to edit: direct delete affordances on nodes and edges,
and a way to select the whole diagram at once. All changes go through the
existing Liveblocks-synced node/edge state.

## Implementation

1. Node toolbar delete.
   - Add a delete button to the floating node toolbar, after the color swatches,
     separated by a thin divider.
   - Use `deleteElements({ nodes: [{ id }] })` from the React Flow instance so
     the removal flows through `onDelete` and syncs to other users.
   - Label it for assistive tech ("Delete node").

2. Edge label delete.
   - When an edge is hovered or selected, show a delete button next to its
     inline label.
   - Use `deleteElements({ edges: [{ id }] })`.
   - Hide the button while the label is being edited.
   - Label it "Delete connection".

3. Select all.
   - Add a "Select all" button to the canvas control bar (its own group between
     zoom and history) and a `Cmd/Ctrl + A` shortcut.
   - Mark every node selected by pushing `replace` changes through
     `onNodesChange` (not `select` changes — React Flow's single-selection
     reconciler would immediately clear all but one).
   - Disable the button when the canvas has no nodes.
   - `selected` is a local-only node field, so this does not broadcast to other
     users.

## Scope Limits

- alignment and grouping are out of scope
- don’t change node or edge rendering
- keep every mutation on the existing collaborative state flow
- right-drag box-select is a separate follow-on — see `18.2-marquee-selection.md`

## Check When Done

- Node toolbar has a working delete button.
- Edge label has a working delete button that hides during editing.
- Select all button and `Cmd/Ctrl + A` select every node.
- Deletions sync to other users in the same room.
- `npm run build` passes.
